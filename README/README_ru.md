## Что такое DeepJeb?

DeepJeb встраивает окно чата с ИИ прямо в KSP. Спрашивайте что угодно — пишите патчи Module Manager, настраивайте моды, объясняйте орбитальную механику, отлаживайте скрипты kOS или проектируйте ракету, которая не перевернётся при взлёте.

DeepJeb поставляется с обширной **базой знаний о мире KSP**: игровая механика, орбитальная физика (законы Кеплера, дельта-V, гравитационные манёвры), все стандартные небесные тела, принципы проектирования космических аппаратов, контент DLC, соглашения по моддингу и ресурсы сообщества. Но его настоящая сила — **система навыков**: вы можете поместить любой документ `SKILL.md` в папку `Skills/`, и ИИ загрузит его как знания предметной области. Научите его вашему любимому моду, вашему пользовательскому набору планет или вашим личным правилам постройки. Формат навыков открыт и документирован — ваш опыт, ваши правила.

> **Вам нужен собственный API-ключ.** DeepJeb не включает и не предоставляет ИИ-сервисов — вы подключаете его к своему аккаунту OpenAI, Anthropic, Google Gemini, DeepSeek или другому совместимому API. Весь API-трафик идёт напрямую с вашего компьютера к настроенному провайдеру. Вы также можете направить его на локально развёрнутую БЯМ (через Ollama, vLLM или любую конечную точку, совместимую с OpenAI), чтобы полностью контролировать всё самостоятельно.
>
> **Как хранится ваш API-ключ.** В памяти ключ хранится в открытом виде (необходимо для аутентификации API). На диске ключи шифруются с помощью XOR-обфускации с кодировкой Base64 — они никогда не записываются в файл конфигурации в открытом виде. Для OpenAI и Anthropic API-ключи отправляются как HTTP-заголовки Bearer token, которые консоль отладки KSP не регистрирует. API Google Gemini является исключением — см. Известные проблемы ниже.

## Что он умеет?

DeepJeb поставляется с **7 встроенными базами знаний** (Agent Skills) и **7 инструментами файловой системы**, которые ИИ может использовать.

### Базы знаний (Навыки)

| Навык | Описание |
|-------|-------------|
| **Знания о мире KSP** | Стандартная игровая механика, орбитальная физика, небесные тела, проектирование аппаратов, контент DLC, советы по моддингу, ресурсы сообщества |
| **Файлы .craft KSP** | Формат файла .craft, поля PART, кватернионное вращение, узлы крепления, зеркальная симметрия, радиальные размеры, справочник стандартных деталей, инструменты анализа, устранение неполадок |
| **Module Manager** | Синтаксис MM-патчей, операторы, директивы упорядочивания, проверка NEEDS/DEPENDS, переменные, распространённые шаблоны |
| **Программирование kOS** | Справочник языка KerboScript, управление полётом, узлы манёвра, загрузочные файлы, триггеры |
| **Программирование kRPC** | Архитектура, клиентские API Python/C#/Lua, SpaceCenter, AutoPilot, управление кораблём, потоковые данные |
| **MechJeb** | Все модули наведения, интеграция с карьерой, изменение значений в реальном времени через kRPC/kOS |
| **Realism Overhaul** | Полное руководство по набору модов RO/RP-1/RSS — 68 репозиториев, установка, детали, двигатели, жизнеобеспечение, исторические корабли, устранение неполадок |

Навыки сопоставляются автоматически по пересечению ключевых слов с вашим вопросом — 2 лучших совпадения вводятся как контекст.

### Инструменты ИИ-агента

| Инструмент | Что ИИ может делать |
|------|-------------------|
| `read_file` | Читать любой файл в GameData |
| `write_file` | Создать или перезаписать файл (автоматически создаёт каталоги, сохраняет предыдущую версию) |
| `delete_file` | Удалить файл (сначала создаёт резервную копию `.bak` с меткой времени) |
| `list_directory` | Вывести содержимое каталога с размерами файлов и временем изменения |
| `file_exists` | Проверить, существует ли файл или каталог |
| `backup_file` | Создать снимок `.bak` с меткой времени без изменения оригинала |
| `get_game_state` | Сообщить текущее состояние игры KSP (корабль, орбита, биом, ресурсы) |

ИИ может читать файлы Squad/SquadExpansion, но **не может изменять или удалять их**.

### Слэш-команды

Введите `/` в поле ввода, чтобы выполнять команды локально — без обращения к ИИ:

| Команда | Функция |
|--------|---------|
| `/retry` | Отправить ваше последнее сообщение ИИ повторно |
| `/undo` | Удалить последнюю пару обмена из сессии |
| `/help` | Показать все доступные команды |
| `/session` | Показать информацию о текущей сессии (провайдер, модель, количество сообщений) |
| `/game` | Показать текущее состояние игры KSP (сцена, корабль, орбита, биом, ресурсы) |

## Что такое Agent Skill?

Базы знаний DeepJeb — это **Agent Skills** — стандартный формат для упаковки экспертных знаний предметной области с ИИ-ассистентом. Каждый навык — это файл `SKILL.md` с YAML-фронтметтером (название, описание, триггеры) и телом Markdown, содержащим знания. Навыки размещаются в каталоге `Skills/` и загружаются при запуске.

### Как работают навыки

- **[Документация Agent Skills](https://docs.anthropic.com/ru/docs/claude-code/skills)** — официальное руководство (из документации Claude Code)
- **[Создание пользовательских навыков](https://docs.anthropic.com/ru/docs/claude-code/skills#creating-custom-skills)** — руководство по созданию (из документации Claude Code)

Чтобы добавить собственный навык в DeepJeb, создайте файл `SKILL.md` в `GameData/DeepJeb/Skills/{категория}/{имя}/` со следующим содержимым:

```yaml
---
name: имя-вашего-навыка
description: >
  Что охватывает этот навык.
---
# Здесь ваше содержимое знаний
```

Справочные файлы (скрипты, таблицы, примеры) можно разместить в подкаталоге `references/` — они будут внедрены вместе с навыком при совпадении.

### Условная активация навыков

Вы можете использовать поле фронтметтера `when_to_use`, чтобы навык активировался только при наличии определённого мода. ИИ-агент может проверить `GameData/` на наличие установленных модов перед загрузкой навыка:

```yaml
---
name: руководство-по-моему-моду
description: >
  База знаний для MyMod. Активировать только при установленном моде.
when_to_use: |
  Срабатывает, когда папка GameData пользователя содержит "MyMod".
condition: file_exists("MyMod/") -> true
---
# Руководство по настройке MyMod
```

Используйте вызовы инструментов `file_exists` или `list_directory` в качестве условий для управления загрузкой навыков — так DeepJeb не будет загружать нерелевантные знания для модов, которые у вас не установлены.

## Установка

1. Скопируйте папку `DeepJeb/` в каталог KSP `GameData/`
2. Запустите KSP — значок DeepJeb на панели инструментов появляется во всех сценах
3. Нажмите на значок, чтобы открыть окно чата
4. Откройте Настройки, чтобы настроить API-провайдера и модель
5. Начинайте общаться

> **Совет:** Нажмите Enter для отправки, **Ctrl+Enter** или **Shift+Enter** для переноса строки.

**Требования:** KSP 1.12.0+ (протестировано на 1.12.5). Дополнительные моды или зависимости не требуются.

## Известные проблемы

- **Доступность моделей**: Списки моделей загружаются в реальном времени с каждого API-провайдера. Если API недоступен, выпадающий список моделей показывает последний кэшированный список или бесконечно отображает «Загрузка...». Проверьте ваш API-ключ и сетевое подключение.
- **Усечение контекста**: Очень длинные разговоры могут терять более ранние сообщения при приближении к лимиту контекстного окна модели. Периодически используйте `/clear` для длинных сессий.
- **Масштабирование интерфейса**: Окно чата использует фиксированные размеры в пикселях (600×500 по умолчанию). На очень маленьких или очень больших экранах макет может масштабироваться неидеально.
- **Смена сцен KSP**: Окно чата сохраняется при смене сцен, но выполняющаяся генерация ИИ останавливается при загрузке сцены.
- **API-ключ Google Gemini**: Gemini API требует передачи API-ключа как параметра URL-запроса (это дизайн Google, а не выбор DeepJeb). В результате, если вы используете провайдера Google Gemini, ваш API-ключ **может появиться в открытом виде** в журналах консоли отладки KSP при использовании отладки Alt+F12. Ключи для OpenAI и Anthropic отправляются как HTTP-заголовки и не регистрируются.
- **Производительность потоковой передачи**: Очень длинные ответы ИИ могут вызывать незначительные колебания частоты кадров интерфейса при рендеринге токен за токеном.
- **ClickThroughBlocker**: Если у вас установлен ClickThroughBlocker, вам может потребоваться дважды нажать на значок DeepJeb, чтобы открыть или закрыть окно. Это ожидаемо — DeepJeb использует собственное обнаружение кликов.
